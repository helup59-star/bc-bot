# 🎶 بوت أغاني — نسخة تجربة (بوت واحد)

يعتمد على **Lavalink 4.2.2** (ملفك Lavalink.jar) + **Shoukaku** + **discord.js v14**.
البوت نفسه يشغّل Lavalink تلقائياً، فما تحتاج تشغّل شي ثاني.

## التشغيل على Wispbyte
1. ارفع كل الملفات في مجلد واحد (بدون مجلدات فرعية)، وحط **Lavalink.jar** معهم بجانب `index.js`.
2. افتح `config.json` وحط توكن البوت في `DISCORD_TOKEN`.
3. من Discord Developer Portal ← Bot ← فعّل **MESSAGE CONTENT INTENT**.
4. أمر التشغيل: `npm install && node index.js`
5. صلاحيات البوت في السيرفر: View Channel, Send Messages, Embed Links, Connect, Speak.

أول تشغيل ياخذ حوالي دقيقة (ينزّل إضافة يوتيوب الرسمية)، تشوف في اللوج:
`✅ Lavalink جاهز` ثم `🤖 البوت شغّال`.

## الأوامر (تشتغل مع البريفكس `-` وبدونه وأنت في روم صوتي)
- `ش` / `شغل` / `play` + اسم الأغنية أو رابط (يوتيوب، ساوندكلاود، قوائم تشغيل)
- `س` / `سكب` / `تخطي` / `skip`
- `ايقاف` / `توقف` / `وقف` / `stop` (يوقف ويمسح القائمة ويطلع من الروم)
- `247` — **للأونر فقط**: يثبّت البوت في الروم ويرجع تلقائياً بعد إعادة التشغيل. نفس الأمر مرة ثانية يلغيه.

بدون بريفكس: `س` و `وقف` لازم تكون الرسالة الأمر فقط (عشان الكلام العادي ما يشغّلها).

## إعدادات مهمة (config.json)
| المفتاح | الوصف |
|---|---|
| `NO_PREFIX` | `false` لو تبي الأوامر بالبريفكس فقط |
| `LAVALINK_XMX` | رام Lavalink (الافتراضي 384m) — قلّلها لو الرام قليلة |
| `LAVALINK_LOGS` | `true` لعرض لوج Lavalink كامل عند حدوث مشكلة |
| `LAVALINK_AUTOSTART` | `false` لو Lavalink شغّال في سيرفر ثاني (حط `LAVALINK_HOST/PORT/PASSWORD`) |
| `YT_OAUTH` | `true` لو يوتيوب يطلب تسجيل دخول (استخدم حساب جوجل جديد وليس حسابك) |

## لو ما اشتغل
- **"Java غير مثبتة"**: السيرفر ما فيه Java 17+ ← شغّل Lavalink في مكان ثاني واستخدم `LAVALINK_AUTOSTART=false`.
- **الأوامر ما تستجيب**: غالباً MESSAGE CONTENT INTENT مو مفعّل.
- **يوتيوب ما يشتغل**: البوت يجرّب SoundCloud تلقائياً. الحل الأفضل `YT_OAUTH=true` (شوف اللوج، بيعطيك رابط وكود تفعيل).
